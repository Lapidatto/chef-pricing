# Pricing Rules

```text
base cost = purchase price / quantity converted to g, ml, or unit
cost with waste = quantity used * base cost / (1 - waste / 100)
preparation cost = sum of component costs
preparation unit cost = total cost / yield
dish cost = sum of ingredient and preparation costs
suggested price = dish cost / (food cost / 100)
margin = (selling price - cost) / selling price * 100
```

The waste percentage registered for an ingredient is combined with the
recipe-specific waste percentage without simply adding the percentages.
